# LoreVia — public-safe portfolio summary

LoreVia is an AI-powered manuscript intelligence workspace for fiction authors. It organizes a draft into chapters, tracks characters and continuity evidence, and supports chapter-grounded search and analysis. The engineering work includes a Next.js frontend, FastAPI backend, PostgreSQL with pgvector, Celery background processing, durable task state, and Docker-based deployment.

The accompanying media uses only synthetic story examples and application UI captures. It contains no customer text, account data, credentials, host addresses, or production performance claims.
